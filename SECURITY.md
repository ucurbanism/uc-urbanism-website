# Security

This is a static website with no server, database or user accounts of its own, and the repository holds no
passwords, keys or tokens. The parts worth reporting are things like a leaked secret in the history, a way to
publish to the site without being a collaborator, or a script on the site that does something it shouldn't.

## Reporting a problem

Please report privately, not in a public issue:

1. On GitHub, open this repository's **Security** tab and choose **Report a vulnerability**.
2. If that option isn't there, message a club officer through the
   [Connect page](https://uc-urbanism.netlify.app/connect/) and say you have a security report.

A maintainer will reply within a week during the semester. This is a student club run by volunteers, so there is
no bug bounty, but you will be thanked in the changelog if you'd like.

## Supported versions

Only the live site and the `main` branch are maintained.
